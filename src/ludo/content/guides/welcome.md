# You already know this computer

Linux is not a personality. It is an operating system sitting on the same SSD, talking to the same hardware, running the software you already own.

If you can install a driver, pin a taskbar icon, and survive Device Manager, you have the skills. The names change. The jobs do not.

## Distro, desktop, kernel

Three words get mixed together:

- **Kernel** — the engine. You almost never touch it on purpose.
- **Desktop environment** — the panels, launcher, and settings app (KDE Plasma, GNOME, Cinnamon…). This is the part that *feels* like Windows or macOS.
- **Distribution (distro)** — a product that ships the kernel + desktop + software store + defaults. Ubuntu, Fedora, CachyOS, Mint, SteamOS are distros.

You did not "install Linux" in the abstract. You installed a distro. That is why two Linux PCs can look nothing alike and still do the same jobs.

## What actually changes on day one

| Habit from Windows | What Linux does with it |
| --- | --- |
| Drive letters | One folder tree starting at `/` |
| Setup.exe | A package manager or Flathub |
| Run as administrator | `sudo` for one command |
| GeForce Experience | System updates (and NVIDIA's driver package) |
| Steam | Still Steam. Proton is the new compatibility checkbox |

Your files in Documents and Downloads are still yours. Nobody is making you live in a terminal. The terminal is a power tool, not an entrance exam.

## A useful attitude

Treat Linux like moving to a city where the street signs are in another language and the trains actually run. You will look things up. That is competence, not failure.

Skip:

- Random "kernel tweaks" from a six-year-old forum post
- Disabling security features to "go faster"
- Installing NVIDIA drivers from a raw `.run` file because a YouTube video said so

Do:

- Keep the system updated
- Prefer your distro's software store and Flathub
- Check [ProtonDB](https://www.protondb.com) before you assume a game is hopeless
- Let Ludo's checkup tell you what this machine already has

## If you remember one thing

You are not behind. You are bilingual-in-progress. Windows taught you the concepts. Linux is teaching you new nouns.
