# Taskbar, Start menu, and shortcuts

The **desktop environment** is the Windows-shaped part: panels, app menus, workspaces, settings. You can replace it without reinstalling the OS. You probably should not, in week one.

## If you want Windows muscle memory

**KDE Plasma** is the shortest jump: bottom panel, start menu, tray icons, right-click desktop, global themes. **Cinnamon** (Mint) is the other friendly landing.

**GNOME** is more like a tablet-meets-macOS: Super opens an overview, the tray is hidden in the calendar menu, extensions add a taskbar back if you miss it.

None of these choices affect Steam. Proton does not care how pretty your panel is.

## The Super key

It is the Windows key. Typical defaults:

- Super — launcher / overview
- Super+Tab or Alt+Tab — switch windows
- Super+Left/Right — tile
- Super+L — lock
- Print Screen — screenshot

Everything is remappable. If a shortcut fights muscle memory, change it on day one. That is not cheating.

## Workspaces are the feature Windows kept almost hiding

Virtual desktops are first-class. Put Discord on workspace 2, the game on 1, the browser on 3. Gamers who try this rarely go back.

## Displays, HDR, VRR

Wayland is the modern display server. On AMD and Intel it is usually the right default in 2026. NVIDIA is in much better shape than it was in 2022; if a specific feature (HDR, a capture card, an overlay) misbehaves, your distro's community will say whether X11 is still the workaround.

Refresh rate and enabling FreeSync/G-Sync live in Display settings and sometimes in NVIDIA Settings. Per-game tricks often belong in **gamescope**, not in a control panel from 2014.

## If you remember one thing

You are allowed to make it look like Windows. You are also allowed to spend a Saturday in theme settings. Neither makes you more or less of a Linux user.
