# The daily driver app swap

Gaming gets the headlines. Daily driving is whether Discord, the bank website, and the office suite feel boring in a good way.

## Keep these without thinking

- **Browser** — Firefox, Chrome, Chromium, Brave, Edge all have Linux builds. Your bookmarks sync. DRM video (Netflix) works in the official Chrome/Edge builds and in Chromium with the right flags/store.
- **Discord** — native or Flatpak. Voice works. Screenshare on Wayland needed a few years of work; current builds are fine on a current distro.
- **Steam, Spotify, OBS, VS Code/Cursor, Slack** — first-class, or close enough.

## Office

- **LibreOffice** is the native suite. Good enough for most .docx.
- **OnlyOffice** feels closer to Word/Excel.
- **Google Docs / Microsoft 365 in the browser** is what a lot of people actually do.
- **Outlook desktop** is the remaining thorn — use the web app or Evolution/Thunderbird.

## Creative tools

- **Photoshop** — Krita, GIMP, or Photopea in a browser. Affinity is a maybe depending on the year you are reading this; check current Linux status instead of a 2022 thread.
- **Premiere** — DaVinci Resolve has a Linux build with GPU caveats (NVIDIA CUDA is the well-trodden path). Kdenlive and Shotcut are the FOSS options.
- **Ableton / FL Studio** — Bitwig, Ardour, or Wine/Yabridge for VST-heavy setups. This is a hobby with a real learning curve.

## The "just use a browser or a VM" bucket

Banking dongles, vendor-only CAD, some school proctoring, iTunes, and a long tail of .NET enterprise tools. A Windows VM (Boxes, virt-manager, VMware) or a leftover Windows partition is a tool, not a moral failure.

## Fonts and "this document looks ugly"

Install Microsoft core fonts if you must (`ttf-ms-fonts` or the `mscorefonts` package — names vary). Or install the fonts you actually own. Linux is not missing fonts; it is missing *those* fonts.

## If you remember one thing

Daily driving is an app-by-app migration, not a leap of faith. Make a list of the ten things you open before lunch. That list, not a distro war, decides whether Linux sticks.
